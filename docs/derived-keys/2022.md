## The disputed item

**Q17 — Rolle's theorem for f(x) = |x|.** Two defensible readings:

- **Strict reading.** Rolle needs f(a) = f(b) as well as continuity and
  differentiability. For a < b this never holds for f(x) = |x|, so **(D) "never
  applicable"** is right.
- **Conditions-only reading.** If the question is about continuity and
  differentiability alone, then both **(B)** (0 < a < b) and **(C)** (a < b < 0)
  are true — and a single-answer question cannot have two correct options.

Because the readings give different answers and one of them breaks the
single-answer format, this is recorded as `disputed` with **no answer**. It cannot
score. If a second solver resolves it, it becomes `derived-verified`; until then it
stays open.

## Traps that were caught rather than fallen into

Recording these matters more than the answer letters, because they are the
error classes a one-pass key ships silently.

- **Q7 — option (D) is engineered to be wrong.** It uses arg = 4π/5, the value you
  get by dropping the minus sign from the secant. Confirmed numerically: arg is
  −72°, i.e. −2π/5.
- **Q18 — option (C) counts an endpoint.** 3x² = 3 gives x = ±1, but x = −1 is an
  endpoint of the chord, not an interior point with a parallel tangent. One point,
  not two.
- **Q1 — "orthogonal" does not mean "rotation".** det Q = −1, so the reflex to say
  "orthogonal matrices stay orthogonal, so (C)" fails. The product is diagonal.
- **Q3 — (B) is refused by the data, not by opinion.** det = −4, so singular is
  simply false, and distinct real eigenvalues settle (C).

## A transcription defect found on the way

**Q8** is rendered in `pyq-md/2022.md` as `iz² + z² − z + i = 0`, which is not a
solvable statement of the question. The official page image shows **z³**. The key
uses the official version; `pyq-md/` was **not** edited, consistent with the
standing rule that corrections to preserved content are an editorial decision.

## How to attack this key

Any of the following is more useful than agreement:

1. **Re-derive one of the machine-checked answers by hand.** If the code check and
   the hand calculation disagree, the code is wrong or the model of the question is.
2. **Take Q17.** A single defensible argument for one option settles it.
3. **Cross-check Q10 and Q11**, the two without machine checks — they are the most
   likely to be wrong.
4. **Confirm the Q8 defect** on page 4 of the official booklet before anyone edits
   the corpus.

The prompt to hand a second model is `SOLVER-PROMPT.md`; send back only the
`DISAGREE`, `AMBIGUOUS` and `UNDETERMINED` lines.
