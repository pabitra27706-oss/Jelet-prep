## Why five questions are disputed

Four of the five are not my uncertainty; they are defects in the paper or its
option set.

| Q   | Problem                                                                                                          |
| --- | ---------------------------------------------------------------------------------------------------------------- |
| 17  | Rolle's theorem on \|x\|: the strict reading gives (D), the conditions-only reading makes both (B) and (C) true. |
| 40  | The differential equation solves to x = y(1 − ln y), so y(−3) = **4.97** — no option matches (3, 2, −1, 4).      |
| 59  | No reading of the lens-plus-mirror combination gives F = 25 cm for any of the four options.                      |
| 61  | Momentum forces v′ = 2√3, but both speed options are printed as √3.                                              |
| 77  | Bohr's model applies to one-electron species, which makes both (C) and (D) defensible.                           |

A one-pass key that quietly picked the nearest option would have hidden all of
this. The `disputed` tier exists so it cannot score.

## Ten errors in my own first pass

This batch was drafted, then **re-checked against the option lettering**, and ten
answers were wrong. They are corrected in the key and recorded here because the
correction rate is the most useful number in this document:

| Q   | First draft | Corrected    | Cause                                                           |
| --- | ----------- | ------------ | --------------------------------------------------------------- |
| 45  | A           | **C**        | Components (1, 2) are option (C), not (A).                      |
| 48  | C           | **D**        | 4mg/((2m+M)R) is (D); (B) has 2M+m, a different combination.    |
| 50  | B           | **A**        | Sign error in the volume ratio: σ = (1−0.4)/2 = 0.3.            |
| 54  | C           | **B**        | 150 cm³ is option (B).                                          |
| 58  | C           | **B**        | Used sec² instead of 1/sin²; μ² = 1.77.                         |
| 59  | C           | **disputed** | No option gives F = 25 cm.                                      |
| 62  | D           | **C**        | Only (C) has a curve, a horizontal and a vertical segment.      |
| 66  | A,C,D       | **A,B,D**    | 4 degrees of freedom, so (C) is false and (B) true.             |
| 69  | A,C,D       | **C**        | Final image is virtual, 30 cm left of the lens; only (C) holds. |
| 60  | B           | **D**        | Work function 1.126 eV is option (D) 1.12.                      |

Ten percent. The arithmetic was right in most of these; the **option letter** was
wrong. That is the specific failure a second solver catches cheaply, and the
reason nothing here is tiered `derived-verified`.
