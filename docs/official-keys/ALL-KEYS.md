## How these were checked

- **2023, 2024, 2025** are transcriptions of the board's own final-key notices.
  `npm run keys:official` verifies each is a complete 100-question table whose
  four series columns are permutations of 1–100.
- **Booklet series** was determined empirically per paper, not assumed: questions
  were solved from the booklet pages and matched against all four candidate
  columns. Only Set A fits (2023: 5/5; 2024: 18/19; 2025: 3/3).
- **2022** is derived, because no official key exists for it.

## Known limits

- The transcriptions are hand-typed. The audit checks structure, not correctness —
  a mistyped letter would pass.
- 2017, 2018, 2019 and 2021 have **no official keys** and are **not keyed here**.
